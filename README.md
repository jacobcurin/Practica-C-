# Práctica Switch Case en C#

Aplicación de consola que solicita al usuario un número del 1 al 12 y muestra el mes correspondiente mediante una estructura `switch`.

## Conceptos practicados

- Entrada de datos con `Console.ReadLine()`
- Conversión segura con `int.TryParse()`
- Validación de números entre 1 y 12
- Ciclo `while`
- Condicionales `if`
- Estructura `switch`
- Métodos y valores de retorno

## Ejecución

1. Ejecutar la aplicación.
2. Ingresar un número entre 1 y 12.
3. El programa mostrará el mes correspondiente.
4. Si el dato no es válido, solicitará ingresarlo nuevamente.
